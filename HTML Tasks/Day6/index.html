Open Graph Properties

  • og:title - Defines the title displayed when the webpage is shared.
  • og:type - Defines the type of content, such as a website.
  • og:image - Specifies the image displayed in the social media preview.
  • og:url - Specifies the canonical URL of the webpage.
  • og:description - Provides the description shown in the social media preview.
  • og:site_name - Specifies the name of the website or organization.
